# Common permutation laws for rank-one unitary perturbations

This note characterizes when a single probability law on permutations reproduces the squared moduli of every minor of a rank-one unitary perturbation. Write $U=I+(\zeta-1)vv^*$, where $v^*v=1$ and $|\zeta|=1$, and put $p_i=|v_i|^2$ and $c=|\zeta-1|^2$.

In dimension five, a common law exists exactly when $c(1-\sum_i p_i^2)\le3$. In arbitrary dimension, the criterion is expressed by signed set partitions. The proof uses zero minors to restrict permutation cycles, fractional triangle packing to construct the law, and an induction to select an optimal metric. A six-dimensional example shows why the five-dimensional criterion does not extend unchanged.

The common-law condition is stronger than the ordinary Marcus-de Oliveira inclusion, whose weights may depend on the spectra. Drury proved that inclusion for the rank-one phase family; the unrestricted conjecture remains open.
